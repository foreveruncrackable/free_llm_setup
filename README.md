# free_llm_setup
an repo for setting up freellm in few keystrokes
original credits to Tash Ahmed

##setup

$git clone https://github.com/foreveruncrackable/free_llm_setup
$cd free_llm_setup
$sudo ./setup-freellmapi.sh

the script will automatically setup free llm and you can visit it at 
http://localhost:3001/

### api
go to the dashboard -> keys -> select an provider and paste the api key (if you dont know where to
get the api key -> go to a provider website that gives free api key eg:openrouter,groq -> login -> and create an api key.)

after go to the agents and copy paste the given commands to the terminal for the agent you want.
